# 安装

## 环境要求

- [Vue](https://vuejs.org/) `>= 3.2`
- 现代浏览器或 SSR 环境

## 使用包管理器安装

::: code-group

```bash [npm]
npm install sh-design
```

```bash [pnpm]
pnpm add sh-design
```

```bash [yarn]
yarn add sh-design
```

:::

## 引入样式

无论采用哪种使用方式，都需要引入一次样式文件：

```ts
import 'sh-design/dist/style.css'
```
