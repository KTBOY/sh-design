- 组件统一以 Sh 前缀命名（如 ShLazyImage），并在 defineOptions 中声明 name，CSS 类名采用 sh- 前缀 + BEM 风格。
- 新增组件遵循三件套目录约定：`src/components/<kebab-case>/index.ts` 注册导出，`src/components/<kebab-case>/src/*.vue` 实现组件，同时在 `components/index.ts` 与主入口 `src/index.ts` 同步导出。
- README 组件表、`docs/components/*.md` 文档页、`.vitepress/config.ts` 侧边栏三者必须保持同步，可通过 `node scripts/check-components.mjs` 校验。
- 版本号只在 `packages/sh-design/package.json` 一处维护，`src/version.ts` 由构建脚本自动同步，禁止手动修改。
- 提交信息采用约定式格式 `feat(组件名):` / `fix(组件名):` / `docs:` / `chore:`，破坏性变更在 changelog 中标注 ⚠️ 并至少升 minor。
