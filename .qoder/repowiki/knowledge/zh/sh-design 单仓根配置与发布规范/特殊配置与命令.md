环境要求 Node ≥ 18（文档建议 ≥ 22.13，因 pnpm 11 依赖 node:sqlite），pnpm ≥ 8（当前用 v11）。本地开发：`pnpm install && pnpm play`（调试场）/ `pnpm docs:dev`（文档站）/ `pnpm build`（组件库）。发布前需确保本机全局 registry 为淘宝镜像（只读），发布时由 `publishConfig.registry` 强制切回 `https://registry.npmjs.org/`，并使用原生 `npm publish --otp=...`（pnpm 在非交互终端无法处理安全密钥 2FA）。
