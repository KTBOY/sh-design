仓库采用 pnpm workspace 单仓结构，根 package.json 声明 `private: true` 并通过 scripts 以 `pnpm --filter` 路由到三个子包：`packages/sh-design`（组件库）、`docs`（VitePress 文档站）、`play`（调试场）。根 tsconfig.json 通过 `paths` 把 `sh-design` 别名指向 `packages/sh-design/src/index.ts`，使 docs/play 可直接 import 组件源码进行类型检查。ESLint 使用 flat config + typescript-eslint + eslint-plugin-vue + eslint-config-prettier 统一校验；`.editorconfig`、`.prettierrc.json`、`.gitattributes`、`.gitignore`、`.npmrc` 等文件提供跨工具链一致行为。`pnpm-workspace.yaml` 通过 `allowBuilds` 显式允许 esbuild/vue-demi 的 postinstall 脚本，适配 pnpm v11 的安全策略。发布体系由 `发布npm指南.md`（npm 官方源 + OIDC Trusted Publishing）和 `组件发布流程.md`（组件→文档→changelog→版本→CI 全链路）驱动，并辅以根目录 `release.bat` 串联本地验证、提交推送与打 tag 发版。
