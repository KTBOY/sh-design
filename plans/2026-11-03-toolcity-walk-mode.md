# 城市视图「人物漫游」功能实施计划

**Goal:** 在首页 3D 产品街区的「全景」控件旁增加「漫游」入口：点按后镜头推进到街区内部，出现一个低多边形小人，可用键盘（WASD/方向键）或屏幕方向键在街区内行走，能绕建筑、过拱桥、走到任何地标跟前点击查看作品；退出后回到全景。

**当前阶段:** 方案待放行（代码零改动）。放行后按第 4 节分阶段实施，每阶段自检后更新本文档状态。

**非目标:** 不做第一人称视角、不做室内场景、不做收集/任务等玩法系统、不改动现有街区模型与交互（选中光束、入场生长、日夜切换、铭牌投影全部保留）。

## 1. 现状与切入点（已实读）

| 事实                                                | 位置                                                                                                      |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |

| 拖拽 ±18°/±8°、松手回弹                             | `product-stage.ts:33-34`、`:314-325`                                                                      |

| 屋顶铭牌为 DOM 投影，随 `growthOf` 长高             | `product-stage.ts:365-375`                                                                                |
| 「全景」按钮在舞台右下角                            | `ToolCityStage.vue`（`.tc-stage__reset`）                                                                 |
| 街区模型：地上平台 x∈[-30,30] z∈[-30,26]，河道贴西侧、拱桥在 `x≈-20.3, z≈-1.5`（桥面 y≈0.84，两侧坡道） | `district.ts` `buildWaterfront()`                                                                         |
| 地标坐标与建筑占地                                  | `landmarks.ts` + `district.ts` `BUILDINGS`（如 `sh-design` 7.2×5.8、`shuke-lab-flux` 5.4×5.0）             |
| 场景合批会合并同组静态网格                          | `district-modeling.ts` `batch()`——人物摆动肢体必须放在街区根组之外，避免被合批                          |

结论：**保留正交相机**，用「等距跟随」实现漫游（沙盘俯视视角推进到人物背后），不引入透视相机；人物作为独立对象挂在 `scene` 上，不参与街区合批。

## 2. 方案

### 2.1 相机（D1 定案）

- 进入漫游：焦点从当前全景焦点缓动到人物出生点，`viewScale`（新增，替代原 zoom 的直接赋值）从 1 缓动到 **0.42**（约放大 2.4 倍，人物屏高约 7%）。
- 跟随时：焦点每帧向人物位置做平滑追随（k≈delta×8），保持原正交角度（`baseTheta/basePhi` + 小轨道偏移）。
- 漫游中拖拽仍做 ±18°/±8° 转视角 + 回弹；Ctrl/⌘+滚轮在 **0.30–0.62** 内调视距；Esc 退出。
- 选中建筑（点击/索引）在漫游中**不再**拉动相机（`select()` 的焦点动画在漫游态跳过），只更新右侧详情。

### 2.2 人物（D2 定案）

- 新文件 `theme/components/toolcity/scene/walker.ts`，复用 `DistrictModeling` 的几何/材质工具，独立实例、独立 dispose。
- 造型：低多边形小人，身高 **1.15** 世界单位；奶油白身体（`COLORS.cream`）+ 石灰岩色四肢 + 一小块金色围巾（`COLORS.gold`）；无面部细节，与街区的无脸沙盘气质一致。
- 动画：行走时四肢 sin 摆动（±0.55 rad）+ 身体轻微起伏；站立时轻微呼吸；朝向按移动方向最短角平滑转身。
- 投射阴影；`castShadow=true`。

### 2.3 操控（D3/D4 定案）

- 桌面：WASD/方向键移动（速度 3.4 u/s，Shift 5.4），屏幕方向按相机水平朝向换算；窗口失焦/切后台清空按键，防卡键。
- 触摸端：舞台左下角显示 4 键方向盘（真实 `<button>`，pointerdown/up 按住生效，aria-label 齐全），不依赖摇杆。
- 走路时方向键 `preventDefault`，避免页面跟着滚动；Esc 退出漫游。
- 点击建筑仍然选中（沿用现有 pick），悬停高亮保留。

### 2.4 碰撞（D5 定案）

- 由 `district.ts` 暴露 `canWalk(x, z): boolean` 与 `groundY(x, z): number`，几何知识留在街区内部：
  - 建筑：每个可见地标一个轴对齐矩形（`BUILDINGS` 尺寸 + 0.5 余量），axis-separated 位移实现贴墙滑动。
  - 世界边界：x∈[-28.4, 28.4]、z∈[-28.4, 24.4]。
  - 河道：到河道折线距离 < 3.9 不可走；**拱桥可通行**（桥面矩形 `x∈[-26.0,-14.6] z∈[-2.35,-0.65]` 放行），`groundY` 在桥面上返回 0.84、坡道线性过渡、其余地面 0.03。
- 树木、长椅、小船等装饰不参与碰撞（沙盘级宽容度，避免撞空气）。

### 2.5 铭牌与提示（D6 定案）

- 漫游中隐藏屋顶 DOM 铭牌（`.tc-stage__label` 收起），避免放大后标签堆叠。
- 靠近建筑（≤5.5 单位）时在人物上方显示一枚小签：建筑功能名 + 产品名，可点击选中；离开即收。
- 舞台底部显示操作提示条：「WASD / 方向键走动 · 拖拽转视角 · 点击建筑查看 · Esc 退出」（触摸端文案自动换成方向键版本）。

### 2.6 进入/退出过渡（D7 定案）

- 进入：镜头推进（≈700ms，easeOutCubic）+ 人物 0→1 长出；出生点默认 **中央空地 (0, 7)**（已核对不在任何建筑/河道碰撞体内）。
- 退出：镜头回到全景焦点 (0,0,0)、`viewScale` 回 1、方位/俯仰归零。
- `prefers-reduced-motion`：过渡即时完成，人物摆臂动画关闭。

### 2.7 控件与状态（D8 定案）

- `ToolCityStage` 右下角在「全景」旁新增「漫游」按钮；漫游中变为「退出」。
- 「全景」语义扩展：漫游中点击 = 退出漫游并复位全景（含 zoom 复位，顺带修掉现在全景不复位缩放的小问题）。
- 舞台对外新增 `ProductStage.setWalk(on)`；ToolCityStage 用 `walking` ref 驱动铭牌显隐、按钮态与提示条。

### 2.8 性能与无障碍（D9 定案）

- 漫游中或镜头跟随时保持全帧率、逐帧更新阴影贴图；静止 ≥0.5s 回落到现有 25fps 节流。
- 人物约 +8–10 个 draw call，可接受；不新增贴图。
- 进入/退出通过 `role="status"` 播报；方向盘按钮可键盘聚焦；画布保持 `aria-hidden`，下方作品索引仍是完整替代入口。
- 日夜、入场生长、选中光束、坐标虚线等既有逻辑不动。

## 6. 风险与回退

- **正交放大后的比例感**：人物 1.15 单位与建筑门脸（约 1–2 单位）同量级，若观感偏大/偏小，只调 `walker.ts` 的根缩放，不改相机。
- **桥面通行手感**：坡道为视觉几何，`groundY` 用线性近似；若接缝突兀，退化为「桥面禁行、河道完全阻挡」（D5 的子退化项）。
- **低端机性能**：人物 + 逐帧阴影是新增开销；若掉帧，先关人物阴影（保留投射在地面的圆形贴片假影），再降漫游帧率。
- **移动端误触**：方向盘只出现在 `(hover: none)` 设备；桌面不渲染，避免挤占画布。
