## 1. 体验定义

### 1.1 页面位置

并入 `.home-products`，复用现有「更多工具」头部，不新增第二个区块标题：

```
更多工具 header
  └─ 3D 舞台（本计划新增，约 180vh 滚动段 + sticky 画面）
       └─ 静态卡片墙（现有 7 张 ProductCard，保持不变）
            └─ 查看全部作品（现有）
```

3D 舞台承担「封面 / 氛围」职责，静态卡片墙继续承担扫读、SEO、键盘导航与移动端可用性。两者不互斥。

### 1.2 镜头脚本

| 滚动进度 | 画面 |
| --- | --- |
| 0 - 0.12 | 城市远景 + 第一张卡片入画，标题区自然滚出 |
| 0.12 - 0.82 | 相机沿城市光路推进，7 张卡片依次从画面右侧掠过，城市天际线在下方展开 |
| 0.82 - 1.0 | 相机抬升，最后一张卡片与城市全景收尾，画面淡出到静态卡片墙 |

- 使用原生滚动 + `position: sticky`，不做滚轮劫持、不改滚动速度。
- 指针只做小幅视差（±1.5 世界单位），不影响点击。
- 卡片在接近相机时最清晰，远处由透明度 + 1px 内模糊衰减（CSS3D 无法吃 WebGL 雾）。

### 1.3 图层顺序

| 层 | 内容 | 渲染方式 |
| --- | --- | --- |
| L0 | 页面底色 + CursorGlow 极光 | 现有 CSS |
| L1 | 远景城市、雾 | WebGL |
| L2 | 地面点阵、蓝色光路、节点 | WebGL |
| L3 | 中近景建筑、窗格灯光、轮廓线 | WebGL |
| L4 | 产品卡片（真实 DOM） | CSS3DRenderer |
| L5 | 飘浮猫爪粒子 | WebGL Points（复用 CursorGlow 的品牌符号） |
| L6 | 标题、滚动提示、上下渐隐遮罩 | 普通 DOM |

## 2. 技术架构

### 2.1 渲染分层：WebGL + CSS3D 混合

- 一个 `PerspectiveCamera` 同时驱动两个 renderer：
  - `WebGLRenderer({ alpha: true, antialias: true })`：城市、地面、光路、粒子。
  - `CSS3DRenderer`：7 张真实 `ProductCard` DOM，中文清晰、链接语义保留、可直接复用现有样式。
- 两个 canvas/容器绝对定位重叠，尺寸由同一个 `ResizeObserver` 驱动。
- 不使用后处理（bloom/DOF）：光晕用加色透明贴片与 CSS 阴影模拟，避免额外通道与移动端开销。

### 2.2 城市生成

- 确定性随机（固定 seed），保证每次刷新与截图一致；不依赖外部模型/贴图。
- `InstancedMesh` + 共享 `BoxGeometry`：约 140–180 个建筑实例，沿光路两侧分布，中央留出卡片走廊。
- 每栋建筑由 1–3 段体块叠成退台轮廓，高度/进深/色相由 seed 决定；近景建筑合并为一组 `LineSegments` 描边（1 个 draw call）。
- 建筑材质用自定义 `ShaderMaterial`：
  - 浅色主题：纸白 / 冷灰立面 + 低强度蓝色窗格 + 顶部微高光；
  - 深色主题：深蓝灰立面 + 青色点窗；
  - 窗格由 `fract(uv * grid)` + 每实例 seed 生成，不使用贴图。
- 雾：`FogExp2` 与页面底色对齐，城市向远处自然溶入背景。
- 地面：点阵 shader + 径向淡出；光路沿 `CatmullRomCurve3` 生成带状几何，叠加两层透明度做发光边缘。
- 粒子：一张运行时用 Canvas 画的爪印贴图，40 个左右 Points，缓慢上浮；减少动态时静止。

### 2.3 卡片

- 位置：沿同一条 `CatmullRomCurve3` 取 7 个参数点，悬浮于屋顶上方。
- 朝向：每帧 `lookAt(camera)` 做轻量 billboard，附少量固定 yaw/pitch 避免死板；每张卡片独立轻微上下浮动。
- 尺寸：CSS3DObject 以固定像素宽度（约 340–360px）创建，按相机距离换算世界缩放，保证桌面端文字可读。
- 交互：悬停抬升 + 蓝色描边（CSS）；点击滚动定位到下方对应的静态卡片并短暂高亮。3D 卡片默认 `aria-hidden`、不进入 Tab 序列，真正的可访问入口是静态卡片墙。
- 主题：复用 `.home-products :deep(.p-card)` 的暗色覆盖；CSS3D 的 DOM 仍在该作用域内。

### 2.4 滚动与相机

- `HomeToolCity` 外层高度约 180vh，内层 `position: sticky; top: 64px; height: calc(100vh - 64px)`。
- `progress = clamp((scrollY - 舞台顶部) / (舞台高度 - 视口高度), 0, 1)`，rAF 内做阻尼插值。
- 相机位置/视线目标取曲线采样点，另加指针视差与轻微呼吸浮动。
- 静止 700ms 后停止 rAF；离开视口、页面隐藏、`prefers-reduced-motion` 时完全停帧。
- 不监听 `wheel`，不调用 `preventDefault`，移动端保持原生滚动。

### 2.5 生命周期与降级

| 场景 | 行为 |
| --- | --- |
| 正常桌面 | 懒加载 three → sticky 滚动场景 |
| `prefers-reduced-motion: reduce` | 不加载 three，渲染静态海报帧（构建期从场景导出 WebP），无 sticky |
| 移动端 / 粗指针 | 静态海报帧 + CSS 轻微视差；不运行 WebGL |
| WebGL 不可用 / 上下文丢失 | 同一海报帧 + 静态卡片墙 |
| 动态 import 失败 | 海报帧，不阻塞页面其余部分 |
| 路由离开 | `dispose()` 几何、材质、纹理、renderer，清空 DOM |

- SSR 安全：three 只在 `onMounted` 内动态 `import()`；服务端输出海报占位与静态卡片墙，不产生 hydration mismatch。
- 首屏不加载 three；用 `IntersectionObserver` 在距舞台 400px 时预取。

### 2.6 主题

- 明暗切换时只更新 shader uniform / 雾色 / 底色，不重建场景。
- 颜色来源：品牌色 `#2563eb`、`#22d3ee` 与页面底色沿用现有 token；新增 `scene/palette.ts` 集中维护 WebGL 侧调色板。
- 卡片暗色样式继续由 `HomeProducts.vue` 的 `:deep` 规则提供，避免第二套卡片皮肤。

## 7. 风险与规避

| 风险 | 规避 |
| --- | --- |
| CSS3D 卡片在 3D 中文字发虚 | 卡片使用固定像素宽度与整数缩放；只在远近衰减时加 ≤1px 模糊，近景保清晰 |
| 城市遮挡卡片 | 生成时在路径两侧留固定走廊半径；相机高度与卡片悬空高度分开调参 |
| sticky 段造成“卡住”错觉 | 使用 native sticky，不劫持滚动；总长度控制在 180vh；底部渐隐提示进入静态列表 |
| three 体积拖慢文档站 | 仅动态 import；离屏预取；chunk 预算 220KB；失败降级海报 |
| 低端机掉帧 | 建筑实例化、无阴影、无后处理、DPR 封顶 2；移动端直接走海报 |
| 暗色主题颜色割裂 | 只改 uniform/雾色，不重建几何；用同一套 token 映射 |
| 与 CursorGlow 叠加过亮 | 舞台背景透明，城市雾色与页面底色一致；极光仅在画面边缘可见 |
